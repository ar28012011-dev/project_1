# Основы CSS — простые элементы

Небольшой проект для изучения CSS: набор простых HTML-элементов со стилями и подробными комментариями.

## Файлы

- `index.html` — страница с примерами элементов
- `styles.css` — стили с комментариями к каждому свойству

## Что на странице

- Заголовки и текст
- Кнопки
- Цветной блок (блочная модель: content → padding → border → margin)
- Списки (ul, ol)
- Форма (input, textarea)
- Таблица
- Flexbox — выравнивание в ряд
- Карточки
- Навигация
- Адаптивность (`@media`)

## Как открыть

Откройте файл `index.html` в браузере — стили подключаются через тег `<link>` в разделе `<head>`.

## Синтаксис CSS

```css
селектор {
    свойство: значение;
}
```

Пример:

```css
h1 {
    color: red;
    font-size: 32px;
}
```
